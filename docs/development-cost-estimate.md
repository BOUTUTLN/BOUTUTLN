## 1. 비용 구분 원칙

| 구분 | 무엇인가 | 언제 발생 | 누가 관리 |
|---|---|---|---|
| **개발 비용** | Claude Code(개발 도구) 구독 또는 개발용 API 사용료 | 개발 기간 | 사용자의 개인 Claude 계정 |
| **연구 비용** | LLM 전략(B·C) 백테스트·실험에 쓰는 AI API 비용 | 실험할 때마다(일회성) | 연구 전용 API 키, 별도 한도 |
| **운영 비용** | 서버, 데이터, 운영 AI API, 백업 | 모의투자 시작부터 매월 | 운영 전용 API 키·계정 |

## 3. 운영 AI API 비용 추정

### 3.1 가정 [가정]
- 거래일: 월 21일(국내·미국 각각)
- 하이브리드(C) 판단 대상: 국내 30종목 + 미국 30종목 = 하루 60종목
  - 종목당 입력 4,000토큰(공통 시스템 프롬프트 2,000은 캐시, 종목 데이터 2,000), 출력 800토큰(사고 과정 포함)
- LLM 단독(B, 비교용): 시장당 1회, 입력 30,000토큰, 출력 3,000토큰
- 뉴스·공시 요약: 중복 제거 후 하루 300건, 건당 입력 600 / 출력 120토큰, Haiku 등급 사용
- 변화 기반 호출(새 정보가 없는 종목은 재분석 생략)은 **적용하지 않은 보수적 수치**입니다.

### 3.2 하루 비용

| 작업 | Sonnet 등급으로 판단 | Opus 등급으로 판단 |
|---|---|---|
| C 판단 입력(비캐시 120K) | $0.24 | $0.48 |
| C 판단 입력(캐시 읽기 120K) | $0.02 | $0.02 |
| C 판단 출력(48K) | $0.48 | $0.96 |
| B 판단(입력 60K, 출력 6K) | $0.18 | $0.36 |
| 뉴스 요약(Haiku 등급, 입력 180K, 출력 36K) | $0.04 | $0.04 |
| **하루 합계** | **약 $0.96** | **약 $1.86** |

### 3.3 월 비용

| 시나리오 | 계산 | 월 비용 |
|---|---|---|
| Sonnet 등급, 일반 호출 | $0.96 × 21일 × 여유분 1.5배 | **약 $30 (약 4.2만원)** |
| Sonnet 등급, Batch 사용 | 위의 50% | 약 $15 |
| Opus 등급, 일반 호출 | $1.86 × 21일 × 1.5배 | **약 $59 (약 8.2만원)** |
| Opus 등급, Batch 사용 | 위의 50% | 약 $30 |
| 정량 단독(A, AI 끔) | — | $0 |

> 실거래 단계에서 B(비교용)를 끄면 Sonnet 등급 기준으로 약 20% 줄어듭니다.

### 3.4 연구(LLM 백테스트) 일회성 비용 [가정]
- LLM 전략은 모델 학습 컷오프 이후 기간만 평가할 수 있으므로, 현재 쓸 수 있는 기간은 약 80거래일입니다.
- 실험 5회(프롬프트·설정 변경) 기준:
  - Sonnet 등급: 80일 × $0.96 × 5회 ≈ **$385**(Batch 사용 시 약 $190)
  - Opus 등급: 80일 × $1.86 × 5회 ≈ **$745**(Batch 사용 시 약 $370)
- **연구 비용이 운영 비용보다 클 수 있으므로** 실험마다 예산을 정하고, 저장된 응답을 재사용(같은 입력이면 다시 호출하지 않음)합니다.

## 4. 월간 운영 비용 시나리오

| 항목 | 최소 | 권장(기본) | 확장 |
|---|---|---|---|
| 서버 | $12 (2GB) | $24 (4GB) | $44 (8GB) |
| AI API | $0~5 (정량 위주, 요약만) | $30 (Sonnet 등급) | $60 (Opus 등급) |
| 데이터 | $0 | $0~20 | $80 |
| 백업·감시 | $1 | $2 | $5 |
| **월 합계** | **약 $13~18 (약 2~2.5만원)** | **약 $56~76 (약 8~11만원)** | **약 $189 (약 26만원)** |

- 모두 [가정]을 포함한 추정치입니다. 실제 비용은 운영 첫 달 사용량으로 다시 계산합니다.
- **소액 운용일수록 고정비 비중이 큽니다.** 예를 들어 두 장부 합계 2,000만원을 운용하면서 월 10만원을 쓰면, 비용만으로 연 6%의 수익률이 깎입니다. 그래서 AI 비용도 전략 성과에서 차감해 평가합니다(백테스트 설계 4.1절).

## 5. 개발 비용 추정

|---|---|---|---|

- 개발 중에는 KB 실계좌나 운영 AI 키를 사용하지 않으므로, 개발 단계의 API 비용은 연구 실험 비용(3.4절)만 따로 발생합니다.

## 6. 비용 통제 장치 요약 [제안]
1. 운영 AI: 일 $3·월 $60 한도(사용자 결정), 80% 경고, 100%면 AI를 끄고 정량 단독으로 전환
2. 연구 AI: 실험마다 예산 상한, 응답 캐시 재사용
3. Anthropic 콘솔에서 워크스페이스별 지출 한도 설정(설정 가능 범위는 [미확인])

5. 매월 비용 리포트를 텔레그램으로 발송
