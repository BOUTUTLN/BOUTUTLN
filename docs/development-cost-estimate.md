## 3. 비용 통제 규칙 [v0.5 기본 설계]

| 규칙 | 구현 방법 |
|---|---|
| **유료 API 자동 호출 금지** | 모든 외부 호출은 공급자 레지스트리를 거침. `cost_class`가 `paid` 또는 `unknown`이면 승인 파일 없이는 호출 차단. 유료 LLM(Claude API 등) 모듈은 설치·설정 기본값에서 꺼져 있음 |
| **유료 서비스 자동 가입 금지** | 프로그램은 어떤 서비스에도 계정을 만들거나 결제 정보를 입력하지 않음. API 키는 사용자가 직접 발급해 입력 |
| **무료 한도 초과 시 호출 중단** | 공급자별 일·분·초 한도를 설정하고, 도달하면 그날 호출 중단(유료 등급으로 넘어가지 않음) |
| **예상치 못한 유료 전환 방지** | ① Ollama는 로컬 주소(127.0.0.1)만 허용하고 `-cloud`·`:cloud` 태그 모델은 실행 거부, Ollama 계정 로그인 불필요 ② 결제·과금 관련 오류 응답을 받으면 해당 공급자 비활성화 ③ 월 1회 "비용 점검 체크리스트"(KB 수수료 게시 여부, GitHub 사용량, Ollama 설정, 데이터 공급자 약관 변경)를 대시보드에 표시 |
| **0원이 아닌 서비스 별도 표시** | 대시보드 "비용 상태" 화면에 🔴·⚪ 항목을 따로 표시. 설정 파일에도 `cost_class`가 표시됨 |
| **개발용 Claude 구독료와 운영비 분리** | 운영 프로그램은 Claude Code를 쓰지 않고, 기본적으로 어떤 유료 LLM API도 호출하지 않음. 비용 보고서에 개발비·운영비·거래 비용을 따로 표시 |

- 가정: 하루 추가 가동 약 3시간(장 시작 시간대 국내 1시간 + 미국 1시간 + 분석 1시간), 평균 소비전력 150W(로컬 LLM 실행 중 GPU 부하 포함) → 하루 약 0.45kWh, 월 약 13.5kWh

- PC를 원래 계속 켜 두는 경우 추가 전기료는 이보다 작습니다. 이 비용은 "추가 운영비 0원"의 범위 밖(기존 가계 비용)으로 분류합니다.

### 4.2 로컬 LLM 처리 시간(비용 대신 시간 예산)
로컬 LLM은 돈 대신 **시간**이 듭니다. 하루 분석량은 PC 성능에 맞춰 정합니다.

| 가정 | 값 |
|---|---|
| PC | RTX 5060 Ti 16GB, RAM 32GB [확정] |
| 분석 종목 | 정량 후보 30개 중 상위 10~15개(기본 12)를 기본 모델로 분석, 같은 입력으로 비교 모델 분석 |
| 종목당 출력 | 최대 800토큰(사고 과정 끔, 구조화 출력) |
| 하루 출력 토큰 | 기본 모델 약 4,800~12,000토큰 + 비교 모델 같은 양 |
| 처리 시간 | 초당 40토큰 가정 시 모델당 약 2~5분 + 입력 처리·모델 적재 시간 [가정: P2 성능 측정으로 확인] |
| 시간 예산 | 하루 AI 분석 최대 30분(설정). 기본 모델을 먼저 끝내고, 시간이 부족하면 비교 모델 생략 |

## 5. 0원 목표의 현실적 범위

### 5.1 0원으로 가능한 것
- 주가 데이터 수집(KB 이용료가 0원인 경우), 기술적 지표, 정량 전략, 과거 백테스트, 로컬 AI 분석, 자체 모의투자, 손익 관리, 로컬 대시보드
- 하루 1회 자동 실행, PC 재시작 후 자동 복구, 로컬 백업

### 5.2 0원으로 불가능하거나 제한되는 것
| 항목 | 이유 | 무료 대안 |
|---|---|---|
| 미국 생존편향 없는 과거 데이터 | 무료·약관상 문제없는 출처를 찾지 못함 | USD 장부를 ETF 중심으로 구성, 전향적 모의투자로 판단 |
| 뉴스 본문 대량 수집 | 무료 API는 제목·요약만, 본문은 저작권 문제 | 공시 원문(DART·EDGAR)을 1차 자료로 |
| 24시간 무중단 운영 | 개인 PC는 꺼지거나 재부팅됨 | 작업 스케줄러 깨우기 + 놓친 작업 재실행 + 사후 모의 체결(백테스트 설계 3.6절) |
| 고성능 AI 분석 | 로컬 모델은 대형 유료 모델보다 성능이 낮을 수 있음 | 정량 전략 중심, AI는 보조(λ로 영향 제한), 성과를 측정해 개입 축소 |
| 장중 고빈도 매매 | 범위 밖(제외) | — |
| KB 이용료 | 금액 미게시 | 사용자가 신청 과정에서 확인. 유료면 사용 여부를 다시 결정 |

### 5.3 유료가 필요해지면
- 🔴 항목은 이유와 무료 대안을 먼저 보고하고, 사용자가 승인한 경우에만 도입합니다.
- v0.4의 클라우드·유료 API 비용 추정(보관본)을 그때 참고합니다.
