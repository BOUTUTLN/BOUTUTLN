## 1. 결론 요약 [제안]

| 용도 | 국내(KRW 장부) | 미국(USD 장부) |
|---|---|---|
| 실시간 시세·호가(모의투자·운영) | **KB Open API** | **KB Open API** |
| 장기 일봉(백테스트) | KB 차트(1회 최대 5,000건) + pykrx/FinanceDataReader(비공식, 보조) | 무료로 시작(KB 차트), 생존편향 없는 데이터가 필요하면 유료(EODHD, Massive, Sharadar, Norgate 중 선택) |
| 상장폐지 포함 종목 이력 | KRX 정보데이터시스템·KIND(웹, 재배포 제한) | 유료 데이터가 사실상 필요 |
| 재무·공시 | **OpenDART**(무료) | **SEC EDGAR**(무료) |
| 뉴스 | 공시를 1차 "사건" 데이터로 사용하고, 뉴스는 네이버 검색 API(제목·요약) 등 보조 | 공시(8-K 등)를 1차로 사용하고, 뉴스는 Finnhub·Massive 등 보조 |
| 거시·환율 | 한국은행 ECOS, KB 환율 API | FRED |

- **KB Open API는 국내 IP에서만 호출할 수 있습니다.** 2026-10-28 공지로 해외 IP를 통한 접속·API 호출이 차단됐습니다 [확인]. 데이터 수집도 운영 서버(국내 리전)에서만 합니다. 다른 공급자는 이 제한과 관계없습니다.
- **처음에는 무료 공급자로 시작합니다.** 유료 데이터는 생존편향 없는 미국 과거 데이터가 필요할 때 1개만 추가하는 것을 권장합니다.
- 뉴스보다 **공시(DART, EDGAR)**를 AI 입력의 중심으로 둡니다. 무료이고, 공개 시각이 정확하며, 원문 출처가 분명하기 때문입니다.

## 4. Data Provider 인터페이스 설계 [제안]

### 4.1 역할별 인터페이스
```
PriceProvider            일봉/분봉/현재가/호가
CorporateActionProvider  분할, 배당, 권리, 상장폐지
UniverseProvider         날짜별 상장 종목 목록(상장폐지 포함), 업종 분류
FundamentalsProvider     시점별 재무(available_at 포함)
FilingsProvider          공시 목록·원문(접수 시각)
NewsProvider             뉴스(published_at, first_seen_at, 원문 링크)
FxProvider               환율(매매기준율, 시점)
CalendarProvider         거래일, 장 시간, 반일장
```

### 4.2 공통 규칙
- 모든 레코드에 `source`, `event_time`, `available_at`, `ingested_at`, `license_tag`, `quality_flags`를 붙입니다.
- 원본 응답을 그대로 저장(raw 저장소)한 뒤 정규화합니다. 원본이 있으면 공급자를 바꾸거나 파서를 고쳐도 다시 만들 수 있습니다.
- `license_tag`로 재배포 가능 여부를 관리합니다. 예를 들어 KRX 데이터는 대시보드를 외부에 공유할 때 표시하지 않습니다.

### 4.3 공급자 레지스트리와 대체 전략
```
ProviderRegistry
 ├─ 역할별 우선순위 목록 (예: 미국 일봉 = [KB, EODHD, Massive])
 ├─ QuotaManager: 공급자별 토큰버킷, 일·월 호출 한도, 비용 한도
 ├─ HealthMonitor: 연속 실패, 응답 지연, 데이터 이상 → 서킷 브레이커
 └─ CacheLayer: 같은 요청은 캐시, 마지막 정상값 + 신선도 표시
```

| 상황 | 대응 |
|---|---|
| 기본 공급자 장애 | 다음 순위 공급자로 자동 전환하고, 결과에 `fallback_source` 표시 |
| 사용량 초과 | ① 보유 종목 → ② 매매 후보 → ③ 기타 순서로 요청 우선순위를 둠. 뉴스 보강 같은 비필수 작업은 미룸 |
| 모든 공급자 실패(재무·뉴스) | 해당 데이터 없이 동작: 재무가 없으면 가격 기반 팩터만, 뉴스가 없으면 AI 판단 생략(정량 단독) |
| 모든 공급자 실패(시세) | 그 시장은 **그날 매매하지 않음**(보유 유지). 오래된 시세로 주문하지 않음 |
| 약관 변경·서비스 종료 | 원본 저장소로 과거 데이터를 보존하고, 레지스트리에서 공급자만 교체 |
| 공급자 간 값 차이 | 장 마감 후 교차 검증, 허용 오차 초과 시 기록·알림 |
