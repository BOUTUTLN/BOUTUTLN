## 1. 비용 구분 원칙

| 구분 | 무엇인가 | 언제 발생 | 청구 경로 |

**개발용 Claude Code 크레딧과 운영 프로그램의 Anthropic API 비용은 완전히 별개입니다.**
- Claude Code는 Claude 구독의 사용량 한도를 쓰고, 한도를 넘으면 사용량 크레딧이 종량제로 차감됩니다 [확인: claude.com 요금 페이지, 고객지원 문서].
- Max·Team 플랜에 포함된 월간 API 크레딧은 대화형 Claude Code(터미널·IDE·데스크톱·웹)에 쓰이지 않는다고 안내되어 있습니다 [확인: 고객지원 문서 "Monthly API credits for Max and Team plans"].
- Claude Cloud 세션이 구독 한도를 어떤 방식으로 차감하는지는 [미확인]입니다.
- 운영 프로그램은 Claude Code를 쓰지 않고 Anthropic API를 직접 호출하며, 콘솔에서 별도 워크스페이스·API 키로 청구됩니다.

## 3. AI API 비용 산출

### 3.1 공통 가정 [가정]

| 항목 | 값 | 설명 |
|---|---|---|
| 분석 빈도 | 거래일 하루 1회(국내·미국 각각) | 일 1회 리밸런싱 |
| 월 거래일 | 21일 | 국내·미국 근사치 |
| **C(하이브리드) 분석 종목 수** | 하루 60종목(국내 30 + 미국 30) | 정량 후보 |
| C 호출당 입력 | 4,000토큰 = 공통 시스템 프롬프트·스키마 2,000(캐시 가능) + 종목 데이터 2,000(캐시 불가) | |
| C 호출당 출력 | 800토큰(사고 과정 포함) | |
| C 캐시 | 일반 호출: 시장별 첫 호출 1회는 캐시 쓰기, 나머지 29회는 캐시 읽기 / Batch: **캐시 적중을 가정하지 않음**(보수적) | |
| **B(LLM 단독) 호출** | 하루 2회(시장당 1회), 호출당 입력 30,000 / 출력 3,000토큰, 캐시 없음 | 유니버스 100종목 요약 |
| 뉴스·공시 요약 | 하루 300건(중복 제거 후), 건당 입력 600 / 출력 120토큰, Haiku 등급, 캐시 없음 | |
| **재시도율** | 전체 호출의 5%가 1회 재시도 → 비용 × 1.05 | 시간 초과·스키마 오류 |
| 변화 기반 생략 | **적용하지 않음** | 새 정보가 없는 종목을 건너뛰면 실제 비용은 더 낮아짐 |

| Sonnet 등급, 일반 호출 | $1.01 × 21 | 약 $21 | **약 $28** |
| Sonnet 등급, Batch | $0.62 × 21 | 약 $13 | 약 $17 |
| Opus 등급, 일반 호출 | $1.97 × 21 | 약 $41 | **약 $54** |
| Opus 등급, Batch | $1.22 × 21 | 약 $26 | 약 $33 |
| 정량 단독(A, AI 끔) | — | $0 | $0 |

- 운영 여유분 30%는 뉴스가 몰리는 날, 재분석, 프롬프트 수정 후 재실행을 위한 [가정]입니다.
- 실거래 단계에서 B(비교용)를 끄면 위 금액에서 Sonnet 등급 약 19%, Opus 등급 약 19%가 줄어듭니다.
- Batch는 결과가 늦게 올 수 있어(처리 완료 시간 보장 없음 [가정]) 마감 전에 결과가 없으면 그날은 정량 단독으로 진행합니다.

### 3.4 LLM 실험(연구) 비용 산출 근거

v0.3에서 제시한 "실험 5회 $190~745"는 아래 방식으로 계산했던 값입니다.
- 계산식: **평가 거래일 수 × 하루 비용 × 실험 횟수**
- v0.3 가정: 평가 거래일 80일, 하루 비용 Sonnet 등급 $0.96 / Opus 등급 $1.86(재시도 미반영, Sonnet 캐시 읽기 단가 오기), Batch는 일반 호출의 정확히 50%로 계산
- 결과: Sonnet Batch $192 ~ Opus 일반 $744 → "$190~745"

**v0.4 재계산(공식 단가, 재시도 5%, Batch 캐시 미적용)**

| 항목 | 값 |
|---|---|
| 평가 기간 | 학습 데이터 기준 시점(2026년 6월) 이후, 안전 구간 제외 시 2026-07-15 ~ 2026-10-30 → 약 70~75거래일 [가정: 정확한 거래일 수는 캘린더로 계산 필요]. 계산에는 **75거래일** 사용 |
| 종목 분석 개수 | 하루 60종목(C) + B 2회 + 뉴스 300건 (3.1절과 같음) |
| 분석 빈도 | 평가 거래일마다 1회 |
| 입력·출력 토큰 | 3.1절과 같음(C 호출당 4,000/800, B 호출당 30,000/3,000, 뉴스 건당 600/120) |
| 재시도 | 5% |
| 캐시 | 일반 호출은 시스템 프롬프트 캐시 적용, Batch는 미적용 |
| 단가 | 2.1절 공식 단가 |
| 실험 횟수 | 5회(프롬프트·설정 변경) |

| 시나리오 | 계산 | 실험 5회 비용(추정) |
|---|---|---|
| Sonnet 등급, Batch | 75 × $0.62 × 5 | **약 $230** |
| Sonnet 등급, 일반 호출 | 75 × $1.01 × 5 | 약 $380 |
| Opus 등급, Batch | 75 × $1.22 × 5 | 약 $460 |
| Opus 등급, 일반 호출 | 75 × $1.97 × 5 | **약 $740** |

→ **실험 5회 약 $230~740(추정)**. 범위가 v0.3과 비슷한 이유는 평가 기간을 줄인 효과(80 → 75일)와 재시도·Batch 캐시 미적용으로 늘어난 효과가 상쇄됐기 때문입니다.

**비용을 줄이는 방법**
- 뉴스 요약은 실험 사이에 입력이 같으므로 첫 실험 결과를 재사용 → 실험당 약 $0.04 × 75일 절감(작음)
- 프롬프트만 바꾸는 실험은 B를 빼고 C만 실행 → 약 20% 절감
- 먼저 20거래일·국내만으로 작은 실험을 하고, 유망한 설정만 전체 기간으로 확장
- **LLM 과거 백테스트는 참고용**이므로(백테스트 설계 6.3절) 실험 횟수 자체를 제한

## 6. 비용 통제 장치 [v0.4 기본 설계]
1. 운영 AI: 일·월 한도(사용자 결정, 예: 일 $3 / 월 $60), 80% 경고, 100%면 AI를 끄고 정량 단독으로 전환
2. 연구 AI: 실험마다 예산 상한, 같은 입력의 응답은 재사용
3. Anthropic 콘솔에서 워크스페이스별 지출 한도 설정(설정 가능 범위는 [미확인])
4. 데이터: 무료로 시작, 유료는 필요성이 검증된 1개만 추가
5. 매월 비용 리포트를 텔레그램으로 발송(개발·연구·운영 구분)
