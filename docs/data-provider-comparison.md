> 최종 수정일: 2026-10-30 · 관련 문서: [PLAN.md](../PLAN.md), [비용 추정](development-cost-estimate.md)
> 이전 판(v0.4, 유료 공급자 포함 비교): [docs/archive/v0.4/data-provider-comparison.md](archive/v0.4/data-provider-comparison.md)
>
> **비용 분류(이 문서 전체 공통)**
> - 🟢 **무료로 이용 가능**: 비용 없음, 의미 있는 사용 제한 없음
> - 🟡 **무료지만 사용 제한 있음**: 무료이지만 호출 한도·키 발급·용도 제한이 있음
> - 🟠 **조건부 무료**: 개인 용도 한정, 비공식 경로, 약관상 회색지대 등 조건이 붙음

> - ⚪ **확인 필요**: 요금이나 조건을 공식 자료로 확인하지 못함. **무료로 가정하지 않음**

## 2. 국내 시장

### 2.1 KB증권 Open API — ⚪ 확인 필요

| 항목 | 내용 | 근거 |
|---|---|---|
| 이용료 | 약관 제11조: "회사는 Open API 서비스 이용 고객에게 서비스 제공의 대가로 수수료를 부과한다. 다만, 회사는 수수료를 0원으로 정할 수 있다." 수수료율·납부 기준은 "회사 홈페이지 또는 포털사이트에 게시"한다고 되어 있으나, **확인한 포털 페이지에서 게시된 금액을 찾지 못함** | [확인: KB증권 Open API 서비스 이용약관(일반 고객용), 2026-07-16 시행] / 금액 [미확인] |
| 위탁수수료 | 실제 매매가 체결되면 「매매거래계좌설정약관」의 위탁수수료가 별도로 부과됨(약관 제11조 ③) | [확인] |
| 이용 범위 | 시세정보는 **본인 자산의 투자 목적에 한해** 이용. 제3자 분배·제공·재전송·판매·배포 금지, 상업적 용도(투자정보·자문 서비스, 웹사이트·앱 제공 등) 금지(약관 제5조 ③) | [확인] |
| 대상 | 개인 고객. 법인 고객은 제외(약관 제5조 ⑦) | [확인] |
| 자동매매 | 고객이 자동화된 매매 프로그램을 운용할 때의 위험을 고객이 인지·동의한다는 조항이 있음(약관 제5조 ⑧ 3호). 확인한 범위에서 자동매매 금지 조항은 없음 | [확인] |
| 호출 제한 | 유량제어 정책을 "홈페이지 또는 포털사이트에 게시"한다고 되어 있으나 수치는 찾지 못함(약관 제12조) | [확인] / 수치 [미확인] |
| 접속 조건 | 해외 IP 접속·호출 차단, 국내 IP는 이용 가능(2026-10-28 공지) | [확인] |
| 과거 범위 | 차트 1회 최대 5,000건. 전체 보관 기간 [미확인] | [확인] |
| 보관 | 확인한 약관 범위에서 개인 저장을 제한하는 조항은 찾지 못함. 단, 제3자 제공·재배포는 금지 → **GitHub 등 외부 저장소에 KB 시세 데이터를 올리지 않음** | [확인] / [제안] |

## 3. 미국 시장

### 3.1 공급자

| 공급자 | 데이터 | 분류 | API·호출 제한 | 갱신 | 과거 범위 | 개인/상업 이용 | 근거 |
|---|---|---|---|---|---|---|---|
| **KB증권 Open API** | 시세, 10단계 호가, 차트(NAS/NYS/AMX) | ⚪ | 2.1절과 같음 | 실시간/지연(필드로 구분) | 차트 1회 5,000건 | 본인 투자 목적 한정 | [확인] |
| **SEC EDGAR** | 공시 원문, XBRL 재무, 접수 시각 | 🟡 | 키 불필요, **초당 10회**, User-Agent에 이름·연락처 필수 | 공시 즉시 | 장기 | 공공 정보 | [확인: SEC] |
| **FRED** | 금리·거시 | 🟡 | 무료 키 필요, 분당 120회로 알려짐 | 지표별 | 장기 | 일부 시리즈는 원 출처의 재사용 조건 적용 | [2차] |
| **yfinance(Yahoo Finance)** | 일봉·분봉, 기업행사 | 🟠 | 비공식, 한도 비공개, 중단 위험 | 일 단위 | 장기 | yfinance 프로젝트는 "개인 용도"라고 안내. Yahoo 약관은 개인적·비양도 라이선스 | [2차] |
| **Stooq** | 일봉 CSV | 🟡 / ⚪ | 2026년 초부터 API 키(CAPTCHA) 필요, 낮은 일일 한도 보고 | 일 단위 | 장기 | 약관 미확인 | [2차] |
| Finnhub, Alpha Vantage, FMP, Tiingo, EODHD, Massive | 시세·재무·뉴스 | 무료 등급 🟡 / 상위 등급 🔴 | 무료 등급은 한도가 작거나 개인용 | — | — | 무료 등급 대부분 개인용 | [2차] → **기본 구성에서 제외**(필요 시 무료 등급만, 사용자 승인 후) |
| Sharadar, Norgate | 상장폐지 포함 가격·재무 | 🔴 | — | — | 장기 | 계약 조건 | [2차] → **제외** |

### 3.2 유료 데이터가 꼭 필요한가: 미국 생존편향 문제
- **이유:** 백테스트에서 상장폐지된 미국 종목이 빠지면 성과가 부풀려집니다. 상장폐지 종목까지 포함한 미국 데이터를 무료로, 약관상 문제없이 얻을 방법은 찾지 못했습니다.
- **유료 대안:** Sharadar·Norgate 등(🔴, 사용자 승인 필요)

### 3.3 무료 대안 [제안 — 유료 도입 전에 먼저 적용]
1. **USD 장부 1차 유니버스를 ETF 중심으로 구성**: 지수·섹터 ETF는 상장폐지가 드물어 생존편향 영향이 작습니다.
2. 개별 주식을 쓴다면 **초대형주로 한정**하고, 결과에 "생존편향 있음" 경고를 붙입니다.
3. 생존편향 경고가 붙은 결과는 G1 승인 근거로 쓰지 않습니다(v0.4 규칙 유지). USD 장부 G1은 ETF 유니버스 결과로 판단합니다.
4. 최종 판단은 생존편향이 없는 **전향적 모의투자**로 합니다.

## 4. 무료 한도 관리와 대체 전략 [제안]

### 4.1 공급자 레지스트리의 비용 등급
모든 공급자 설정에 `cost_class`(free / free_limited / conditional_free / paid / unknown)와 `daily_limit`, `per_second_limit`, `license_tag`를 둡니다.

| 규칙 | 동작 |
|---|---|
| `paid` 공급자 | 기본 차단. 사용자 승인 파일(`config/approvals/paid_services.yaml`)에 항목이 있어야만 호출 |
| `unknown` 공급자 | 유료와 같이 취급해 기본 차단. 사용자가 조건을 확인하고 승인 파일에 기록한 경우만 호출(**KB Open API도 여기에 해당**) |
| 무료 한도 도달 | 해당 공급자 호출을 **즉시 중단**(유료 등급으로 자동 전환하지 않음). 다음 날 재개 |
| 한도에 가까움(80%) | 경고 표시, 우선순위 낮은 요청(뉴스 보강 등) 보류 |
| 요금·결제 관련 응답 | 응답에 결제·과금·구독 관련 오류가 오면 해당 공급자를 비활성화하고 알림 |

### 4.2 장애·한도 초과 시 대체
| 상황 | 대응 |
|---|---|
| 기본 공급자 장애 | 다음 순위 **무료** 공급자로 전환, `fallback_source` 표시 |
| 무료 한도 초과 | 보유 종목 → 매매 후보 → 기타 순으로 우선순위. 나머지는 다음 날 |
| 재무·뉴스 모두 실패 | 가격 기반 팩터만으로 진행, AI 판단 생략(정량 단독) |
| 시세 모두 실패 | 그 시장은 **그날 매매하지 않음**(보유 유지) |
| 비공식 라이브러리 중단 | 원본 저장소의 과거 데이터로 계속 사용, 대체 무료 경로 탐색 |

### 4.3 라이선스 준수 [제안]
- KB 시세(본인 투자 목적 한정), KRX 데이터(재배포 금지)는 `license_tag=personal_only`로 표시하고, 대시보드는 **로컬(127.0.0.1)에서만** 보여줍니다.
- 데이터 파일은 Git에 올리지 않습니다(`.gitignore`로 `data/` 전체 제외).
